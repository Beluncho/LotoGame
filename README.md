# 🎲 LotoGame (Русское лото)

Консольная реализация игры «Русское лото» с возможностью игры против компьютера.

## 🎯 Что делает игра

| Компонент | Описание |
|-----------|----------|
| **Мешок с бочонками** | 90 чисел, случайный выбор |
| **Карточка игрока** | 15 чисел (3 строки по 5 чисел) |
| **Ходы** | Компьютер всегда зачёркивает, человек выбирает |
| **Победитель** | Тот, кто первый зачеркнёт все числа |
| **Проигрыш** | Если человек ошибся (зачеркнул не то число или пропустил своё) |

## 🛠 Технологии

| Технология | Назначение |
|------------|------------|
| Python 3 | Язык программирования |
| ООП | Классы и наследование |
| Pytest | Тестирование |
| random | Случайный выбор чисел |

## 🎮 Классы и их методы

### Bag (Мешок)

```python
class Bag:
    def __init__(self, count):        # Мешок с числами от 1 до count
    def __len__(self):                # Количество оставшихся чисел
    def get_random_numbers(self, count)  # Получить count случайных чисел
    def get_next_number(self):         # Получить следующее число (удаляет из мешка)
```

### CardNumber (Число в карточке)

```python
class CardNumber:
```

### Card (Карточка)
```python
class Card:
    def __init__(self, numbers):      # 15 чисел
    def __str__(self):                # Красивый вывод карточки
    def __contains__(self, item):     # Проверка наличия числа
    def cross_out(self, number):      # Зачеркнуть число
    def is_empty(self):               # Все ли числа зачёркнуты?
```

```python
    def turn(self, number):           # Ход компьютера

    def turn(self, number):           # Ход человека с вопросом y/n
```
### ▶️ Запуск игры
#### Установка зависимостей
```bash
pip install pytest
```
#### Запуск игры

```bash
python game.py
```
#### Запуск тестов
```bash
pytest models/ -v
```
